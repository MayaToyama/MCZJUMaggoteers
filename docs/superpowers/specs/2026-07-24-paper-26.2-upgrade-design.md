# Paper 26.2 + MCZJUGameCore 1.0.7 升级设计

**日期：** 2026-07-24  
**状态：** 已批准（ItemCreator = C：暂不安装，可接受 warning + 局内物品缺失）

---

## 目标

将 **Maggoteers** 从 **Paper 1.21.7 / JDK 21 / MGC 1.0.5** 升级到与测试服及 [MCZJUGameCore 1.0.7](https://github.com/mczju-ops/MCZJUGameCore) 一致：**Paper 26.2**、**JDK 25**、**MGC 1.0.7**。

## 环境事实

| 项 | 值 |
|---|---|
| 本地测试服 | `E:\MCpaper`（WSL：`/mnt/e/MCpaper`） |
| 测试服 Paper | `26.2-65-fc9375a`（`version_history.json`） |
| 启动脚本 | `E:\MCpaper\start.bat` → `paper-26.2-65.jar`，要求 **Java 25** |
| 当前 `plugins/` | 尚无 MGC / Maggoteers（仅 spark、bStats） |

## 决策

1. **MGC 版本：** `com.github.mczju-ops:MCZJUGameCore:1.0.7`（GitHub tag，与 MGC `pom` 中 `paper-api: 26.2.build.62-beta` 对齐；build 号与服上 `26.2-65` 同属 26.2 线，编译用 MGC 声明的 API 坐标即可）。
2. **JDK：** Maven `release` **25**，与 MGC 一致。
3. **ItemCreator（用户选 C）：** 测试服**不安装** MCZJUItemCreator；保留 `plugin.yml` `softdepend`；`pom` 保留 `provided` 依赖以便编译 `ItemCreatorApi` 引用；运行时 `ItemService` 已有 API=null 警告路径；`RewardService` 物品校验 warning 可接受。
4. **MGC 接入：** 不重写生命周期；升级后抽查 `Menu(Player,Object...)`、`PlayerExt.getData`、`registerGame` 等与 1.0.5 相同契约（1.0.7 源码已确认 `Menu` 构造未变）。
5. **铁律①②③** 不变。

## 技术风险与对策

| 风险 | 对策 |
|---|---|
| `PotionEffectType.getByName` / `Attribute.valueOf` / `EntityType.valueOf` 在 26.2 编译失败 | 新增 `util/GameRegistries.java` 统一 Registry/NamespacedKey 解析 |
| `VoidGenerator` / `StructurePaster` API 变更 | 按 `mvn compile` 报错逐项改；参照 Paper 26.2 javadoc |
| 无 ItemCreator 导致 WEAPON/SUPPLY/货币外观 | QA 范围排除物品外观；测 STAT/波次/菜单/MGC/持久化 |
| 旧 `plugins/Maggoteers/` 配置未覆盖 | 升级 QA 前按需删 yml（`saveResource(false)` 不覆盖） |

## 验收标准

- `mvn test` 全绿（51+ 逻辑单测）。
- `mvn package` 产出 jar。
- `E:\MCpaper\plugins\` 部署 **MCZJUGameCore-1.0.7.jar** + **Maggoteers-*.jar**（无 ItemCreator）。
- `/mgc join maggoteers` 能开局：虚空世界、波次、职业/休整菜单、胜负结算（物品缺失不阻塞）。
- `CLAUDE.md` / `docs/dev-log.md` 版本基线更新为 26.2 / MGC 1.0.7 / JDK 25。
